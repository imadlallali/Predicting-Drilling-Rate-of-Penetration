# Predicting-Drilling-Rate-of-Penetration
I developed a high-accuracy predictive model for Rate of Penetration (ROP) in Sonatrach's drilling operations. ROP serves as a critical efficiency metric in the energy sector, where precise predictions can substantially reduce operational costs and enhance drilling performance. Given the complexity of ROP prediction, which depends on multiple interdependent drilling parameters including weight on bit, rotational speed, and mud properties this presented a challenging analytical problem.
My role encompassed several key responsibilities: implementing robust data cleaning and preprocessing procedures to remove anomalies and outliers, conducting feature engineering to identify the most significant predictors of ROP, and developing a machine learning solution using an ensemble approach. Specifically, I employed AdaBoost with Random Forest as the base estimator to build the predictive model. The training dataset comprised comprehensive drilling parameters captured from Sonatrach wells over a defined operational period. The resulting model demonstrated strong predictive performance, successfully forecasting ROP with high accuracy.
